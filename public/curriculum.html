            كود اللوح

            اكتبوا نفس الكود على الجهازين عشان يتزامنوا (أي كلمة سرية بسيطة).

            … بيحمّل Firebase

            بعد الاتصال، أي تغيير بيتحفظ ويتزامن تلقائيًا. غيّر حاجة على اللاب → تظهر على الموبايل فورًا.

            تفعيل لأول مرة (في Firebase Console)

            1. Build → Firestore Database → Create database.
            2. Build → Authentication → Sign-in method → فعّل Anonymous.
            3. Firestore → Rules → الصق ده واحفظ:
            rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /boards/{board} {
      allow read, write: if request.auth != null;
    }
  }
}
